# 通用竖版内容样例

这些是中性功能样例，不是用户报告，也不是研究证据。不要把样例事项、数字、状态或来源直接写入真实报告。

- `work-report/`：没有数据文件的工作汇报，展示概览、处理步骤、展开详情与方案切换。
- `materials-review/`：以材料阅读为主，展示来源比较、具体阅读问题和方法说明。
- `mixed-report/`：五条明确标注的测试任务记录，展示少量 CSV 支撑的进度、案例切换和步骤图片。没有探索分析、模型或预测。

这些目录用于结构校验，只有内容与证据文件，不是可直接打开的构建项目。先按已确认的形式运行 `scaffold_project.mjs --mode general-scroll-report --profile <内容类型> --output <新目录>`，再用实际材料组织章节并填充内容。样例的 `newProject: false` 仅表示它们是静态测试夹具；不要复制这个兼容标记到新项目，生成器会记录新项目的完整质量要求。

`report-content.json` 中正文支持有限的 `**加粗**` 语法，适用于必要的动作、数字、差异和条件。不要整段加粗。不能写入可执行 HTML；复杂图表沿用共享证据组件。

参考校准图片在 `reference-calibration/`，只用于观察目录、正文、标题和模块对齐。不要继承图片里的主题、日期、产品或数量；默认正文应比参考报告的讲稿式页面精炼。

运行静态回归：`node scripts/test_general_reports.mjs`。真实浏览器、编辑、打印和断网验证仍按通用竖版指南执行，不能用静态测试代替。
